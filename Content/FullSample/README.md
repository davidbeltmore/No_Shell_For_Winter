# FullSample

## Getting started

## Easy way
Download the repo as a .zip file and extract it within the Content folder of your game project.
Rename the Folder “FullSample” as git may rename it as full FullSample-main or something similar
Open your game project
In Edit → Plugins make sure that ACF Ultimate is installed and activated
Click on the IV button on the topbar
Click on Update To IV button
Click on Update Project Settings button to let the plugin automatically configure all the project settings (NOTE: make a backup of your config folder if you have custom settings as this may override your own configs!)

## “PRO” Way
The way the repo is intended to be used it to setup it a subrepo of your own project. Cloning the repo within the Content folder of your project will help you keeping the sample project always updated as you’d just need to pull / checkout the branch you’d need of the subrepo to upgrade your project to the latest version
